# 07 · 开工前需双方确认的决策点

把这些定了，`05` 映射表填完，就能开工。

## A. 变体 / SKU（最高优先级）
1. 你们后端的变体模型是什么？**是否支持"颜色×尺码"二维、每个组合独立价/图/库存**？（前端强依赖，见 `04` 第 1 条）
2. 变体属性数量是否固定为 2（颜色+尺码），还是支持 N 个轴？
3. `Sku.key` 用什么做唯一标识（后端 SKU id？还是"属性值组合"拼出来的串）？下单要能定位到具体变体。
4. 一个商品最多多少 SKU？是否需要**分页/按需加载**变体矩阵（前端示例有 1000 SKU 的极端情况）？

## B. 价格 / 币种
5. 价格币种？全站前端按 **`$`（USD）** 展示。你们返回的是 USD 还是 CNY？要不要**多币种/汇率/地区定价**？
6. 金额单位：元（带小数）还是**分（整数）**？（前端 `money()` 按"元、2 位小数"格式化）
7. 是否支持**每变体不同价**、**价格区间**、**划线原价/促销折扣**、**阶梯/批发价**？

## C. 业务模式（B2B / B2C）
8. 这个站是面向**零售(C)**、**批发(B)**，还是**混合**？
   - 混合：前端已定策略 = C 端单组合加购 + 多 SKU 商品"暂存选款"；B 端将来加**批量矩阵 + 阶梯价 + MOQ + 账期**（目前未做）。
9. 是否有**起订量 MOQ / 整箱 / 客户分级价**？（汽配类已有 `auto.moq` 概念）

## D. 购物车 & 下单
10. 购物车放**前端(localStorage)** 还是**后端**？（跨设备同步、登录合并购物车 → 需后端购物车）
11. 下单接口字段、运费/税/优惠计算规则、优惠券（前端有 `ONE10` 演示码）、订单状态机。
12. 支付走什么（Stripe/PayPal/线下转账/账期）？前端需按其要求接。

## E. 图片 & 内容
13. 图片是否可**公网直接访问**？私有对象存储需签名 URL。
14. 每商品主图、每 SKU 变体图、每分类/子分类缩略图，**是否都有**？
15. 富文本描述/规格/评价内容从哪来（后端字段？CMS？）；汽配 OE/适配数据是否有。

## F. 搜索 / 列表
16. 搜索/筛选/排序/分页是否**服务端**提供？分页风格（page/limit 还是 cursor）？
17. 列表默认排序、每页条数。

## G. 鉴权 & 账户
18. 登录方式（邮箱密码 / OAuth / OTP）？会话用 **cookie 还是 Bearer token**？（影响前端 `$fetch` 与 SSR）
19. 账户中心需要哪些：订单列表、地址簿、收藏、对账/发票？（前端有占位页）

## H. 交付形态
20. 是**前端整站迁移进你们工程**，还是**前端独立部署、只调你们 API**？
    - 若独立部署：需要你们 API 的 **CORS 白名单 + 测试环境地址 + API 文档(OpenAPI/Swagger)**。
    - 若并入你们仓库：注意 Nuxt 版本/构建/路由基路径。
21. 有无 **OpenAPI / Postman / 示例响应**可直接给？（有则 `05` 映射能很快填完）

## 附：已知前端小问题（不影响对接，记录）
